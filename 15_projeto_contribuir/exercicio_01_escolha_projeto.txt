============================================================
EXERCÍCIO 01 — Escolhendo um Projeto
Dificuldade: Médio
============================================================

OBJETIVO: Escolher um projeto open source adequado para
sua primeira contribuição.

------------------------------------------------------------
PARTE 1 — COMO ESCOLHER
------------------------------------------------------------

Critérios para um bom primeiro projeto:

[ ] Eu uso ou conheço a tecnologia
[ ] A comunidade é ativa (último commit recente)
[ ] Há issues com "good first issue"
[ ] CONTRIBUTING.md está claro
[ ] O código é de tamanho razoável
[ ] Possui testes
