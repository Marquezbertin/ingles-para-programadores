# Módulo 15 — Projeto: Contribuir para Open Source

## O Que Você Vai Aprender

Projeto final: contribuir de verdade para um projeto open source em inglês, aplicando tudo o que aprendeu.

### Objetivos

- Escolher um projeto open source adequado
- Abrir issues e pull requests em inglês
- Participar de discussões em inglês
- Fazer sua primeira contribuição real

---

## Sobre este Módulo

Este é o módulo final do curso. Aqui, você vai **contribuir de verdade** para um projeto open source internacional, usando todo o inglês técnico que aprendeu.

### Fluxo de Contribuição

```
1. Escolha um projeto
2. Leia CONTRIBUTING.md
3. Encontre / crie uma issue
4. Fork o repositório
5. Crie uma branch
6. Faça as mudanças
7. Abra um PR em inglês
8. Interaja na review
9. Merge / acompanhe
```

---

## Como Escolher um Projeto

| Critério | Ideal |
|----------|-------|
| Tamanho | Pequeno a médio |
| Idioma | 100% inglês |
| Comunidade | Ativa e receptiva |
| Tags | "good first issue", "beginner friendly" |
| Sua skill | Relacionado à sua stack |

### Onde encontrar issues para iniciantes

| Recurso | URL |
|---------|-----|

| GitHub labels | github.com/...(label:good-first-issue) |
| First Timers Only | firsttimersonly.com |
| Up For Grabs | up-for-grabs.net |
| CodeTriage | codetriage.com |
