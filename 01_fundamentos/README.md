# Módulo 01 — Fundamentos

## O Que Você Vai Aprender

Neste módulo, vamos cobrir os pilares para entender por que o inglês é essencial na programação e como começar a usar os termos técnicos no dia a dia.

### Objetivos

- Entender por que o inglês é a língua da programação
- Conhecer o alfabeto técnico e pronúncia de termos essenciais
- Familiarizar-se com termos básicos de computação
- Começar a pensar em programação em inglês

---

## Teoria

### Por Que Inglês Importa na Programação?

Toda a documentação oficial de linguagens, frameworks e ferramentas é escrita em inglês. Stack Overflow, GitHub, MDN, tutoriais — tudo em inglês. Quando você domina o inglês técnico, você:

- Acessa documentação original sem depender de traduções
- Resolve problemas mais rápido ao buscar soluções
- Participa de comunidades globais de desenvolvedores
- Contribui para projetos open source internacionais
- Aumenta suas oportunidades profissionais

### Expressões Essenciais

| Em Inglês | Em Português |
|-----------|--------------|
| "How do I...?" | "Como eu faço...?" |
| "I need help with..." | "Preciso de ajuda com..." |
| "Can you explain...?" | "Você pode explicar...?" |
| "What does this mean?" | "O que isso significa?" |
| "I'm getting an error..." | "Estou recebendo um erro..." |
