# Módulo 07 — Verbos Técnicos

## O Que Você Vai Aprender

Domine os verbos técnicos mais usados em programação para descrever ações no dia a dia.

### Objetivos

- Aprender verbos de ação em programação
- Usar verbos corretamente em frases
- Descrever processos de desenvolvimento em inglês
- Comunicar o que você está fazendo em reuniões

---

## Vocabulário do Módulo

### Verbos de Desenvolvimento

| Inglês | Português | Exemplo |
|--------|-----------|---------|
| Implement | Implementar | "Implement the new feature." |
| Refactor | Refatorar | "Refactor the code." |
| Deploy | Publicar | "Deploy to production." |
| Debug | Depurar | "Debug the issue." |
| Iterate | Iterar | "Iterate on the solution." |
| Optimize | Otimizar | "Optimize the performance." |
| Maintain | Manter | "Maintain the codebase." |
| Migrate | Migrar | "Migrate to the new version." |
| Scale | Escalar | "Scale the application." |
| Document | Documentar | "Document the API." |
| Review | Revisar | "Review the code." |
| Merge | Mergear | "Merge the branches." |
| Revert | Reverter | "Revert the changes." |
| Deprecate | Depreciar | "Deprecate the old endpoint." |
| Release | Lançar | "Release version 2.0." |
