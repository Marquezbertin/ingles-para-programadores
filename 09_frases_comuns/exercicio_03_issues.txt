============================================================
EXERCÍCIO 03 — Escrever Issues em Inglês
Dificuldade: Médio
============================================================

OBJETIVO: Criar issues claras e informativas em inglês.

------------------------------------------------------------
PARTE 1 — ESTRUTURA DE UMA ISSUE DE BUG
------------------------------------------------------------

```
Title: [Breve descrição do bug]

## Description
[Descrição do problema]

## Steps to Reproduce
1. [Passo 1]
2. [Passo 2]
3. [Passo 3]

## Expected Behavior
[O que deveria acontecer]

## Actual Behavior
[O que realmente acontece]

## Environment
- OS: [Windows/Mac/Linux]
- Browser: [Chrome/Firefox]
- Version: [v1.2.3]

## Additional Context
[Screenshots, logs, etc.]
```

PARTE 3 — ISSUES DE FEATURE / SUGGESTION
------------------------------------------------------------

Escreva uma issue de feature request:

```
## Feature Request
[Descrição da funcionalidade desejada]

## Problem
[Que problema resolve]

## Proposed Solution
[Como poderia ser implementado]

## Alternative Solutions
[Alternativas consideradas]

## Use Cases
[Exemplos de uso]
```

Complete para: "Adicionar modo escuro"

Problem: "Users with visual sensitivity have __________
reading in __________ mode."

Proposed Solution: "Add a __________ toggle in the
__________ settings that switches between __________
and __________ theme."

Use Cases: "A user working in a __________ environment
at night would prefer the __________ theme."

Respostas: difficulty, light; dark mode, user, light, dark;
dark/low-light, dark
