# Módulo 09 — Frases Comuns

## O Que Você Vai Aprender

Aprenda as frases mais comuns usadas em code reviews, pull requests, issues e comunicação diária com times internacionais.

### Objetivos

- Escrever comentários de code review em inglês
- Criar pull requests e issues em inglês
- Participar de discussões técnicas em inglês
- Comunicar-se de forma clara e profissional

---

## Frases para Code Review

### Aprovação

| Em Inglês | Em Português |
|-----------|--------------|
| "Looks good to me (LGTM)." | "Parece bom para mim." |
| "Great work!" | "Ótimo trabalho!" |
| "Nice solution!" | "Boa solução!" |
| "Approved!" | "Aprovado!" |
| "This is well structured." | "Isso está bem estruturado." |

### Sugestões

| Em Inglês | Em Português |
|-----------|--------------|
| "Consider using X instead of Y." | "Considere usar X em vez de Y." |
| "This could be simplified." | "Isso poderia ser simplificado." |
| "Maybe we can extract this." | "Talvez possamos extrair isso." |
| "What do you think about...?" | "O que você acha de...?" |
| "Have you considered...?" | "Você considerou...?" |

### Pedidos de Mudança

| Em Inglês | Em Português |
|-----------|--------------|
| "Could you please fix this?" | "Você poderia corrigir isso?" |
| "This needs to be updated." | "Isso precisa ser atualizado." |
| "Please add more tests." | "Por favor, adicione mais testes." |
| "This might cause issues." | "Isso pode causar problemas." |
| "Can you explain this part?" | "Você pode explicar esta parte?" |

---

## Frases para Pull Requests

### Descrição

| Em Inglês | Em Português |
|-----------|--------------|
| "This PR adds..." | "Este PR adiciona..." |
| "This PR fixes..." | "Este PR corrige..." |
| "This PR refactors..." | "Este PR refatora..." |
| "Closes #123" | "Fecha #123" |
| "Related to #45" | "Relacionado a #45" |

## Frases para Issues

| Em Inglês | Em Português |
|-----------|--------------|
| "Steps to reproduce:" | "Passos para reproduzir:" |
| "Expected behavior:" | "Comportamento esperado:" |
| "Actual behavior:" | "Comportamento atual:" |

| "I'm getting this error:" | "Estou recebendo este erro:" |
