# Contribuindo

Obrigado pelo interesse em contribuir com o **Inglês para Programadores**! Este projeto faz parte do **Laboratório Tech Social** e depende de contribuições voluntárias.

## Como Contribuir

### 1. Encontre ou crie uma issue

- Procure em Issues por tarefas abertas marcadas como `good first issue`
- Se for reportar um erro de conteúdo ou sugerir melhoria, abra uma issue detalhada

### 2. Faça um fork e clone

```bash
git clone https://github.com/seu-usuario/ingles-para-programadores.git
cd ingles-para-programadores
git checkout -b feat/nome-da-mudanca
```

### 3. Faça suas mudanças

- Mantenha o padrão de módulos existente
- Todos os exercícios devem ter dificuldade (Fácil/Médio/Difícil)
- Vocabulário sempre em inglês com tradução em português
- Não altere a estrutura geral (módulo = README + 6 exercícios)

### 4. Commit e Pull Request

```bash
git add .
git commit -m "feat: add new exercise to module 03"
git push origin feat/nome-da-mudanca
```

Abra um Pull Request com descrição clara do que mudou e por quê.

## Guia de Estilo

- **Idioma das instruções:** Português
- **Vocabulário e exemplos:** Inglês com tradução em português
- **Tom:** Didático, amigável e inclusivo para jovens e adultos a partir de 12 anos
- **Contexto:** Sempre realista (docs, commits, PRs, reuniões)

## Código de Conduta

- Seja respeitoso e acolhedor
- Comente de forma construtiva
- Todos são bem-vindos, independentemente de nível de inglês ou programação
