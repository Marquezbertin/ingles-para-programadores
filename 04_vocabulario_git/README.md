# Módulo 04 — Vocabulário Git

## O Que Você Vai Aprender

Domine o vocabulário essencial do Git e GitHub para trabalhar em equipe e contribuir para projetos.

### Objetivos

- Aprender todos os termos do Git em inglês
- Entender mensagens de erro do Git
- Escrever mensagens de commit em inglês
- Participar de fluxos de trabalho Git em inglês

---

## Vocabulário do Módulo

### Conceitos Básicos

| Inglês | Português | Exemplo |
|--------|-----------|---------|
| Repository | Repositório | "Clone the repository." |
| Commit | Commit | "Make a commit." |
| Branch | Branch | "Create a new branch." |
| Merge | Merge | "Merge the branches." |
| Push | Push | "Push your changes." |
| Pull | Pull | "Pull the latest changes." |
| Clone | Clone | "Clone the repo." |
| Fork | Fork | "Fork the repository." |
| Checkout | Checkout | "Checkout the main branch." |
| Staging | Staging | "Stage the changes." |

### Comandos Git

| Comando | Significado |
|---------|-------------|
| git init | Inicializar repositório |
| git clone | Clonar repositório |
| git add | Adicionar ao staging |
| git commit | Fazer commit |
| git push | Enviar para o remote |
| git pull | Baixar do remote |
| git branch | Criar/listar branches |
| git checkout | Mudar de branch |
| git merge | Merge branches |
| git log | Ver histórico |
| git diff | Ver diferenças |
| git stash | Esconder mudanças |
