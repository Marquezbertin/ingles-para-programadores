============================================================
EXERCÍCIO 05 — APIs REST em Inglês
Dificuldade: Médio
============================================================

OBJETIVO: Entender e descrever APIs REST em inglês.

------------------------------------------------------------
PARTE 1 — MÉTODOS HTTP
------------------------------------------------------------

| Método | Ação    | Exemplo |
|--------|---------|---------|
| GET    | Ler     | "GET /api/users" |
| POST   | Criar   | "POST /api/users" |
| PUT    | Atualizar | "PUT /api/users/1" |
| DELETE | Deletar  | "DELETE /api/users/1" |
| PATCH  | Atualizar parcial | "PATCH /api/users/1" |

------------------------------------------------------------
PARTE 2 — DESCRIÇÃO DE ENDPOINTS
------------------------------------------------------------

Descreva cada endpoint em inglês:

1. GET /api/users
   "________________________________________"
   Resposta: "Returns all users from the database."

2. GET /api/users/1
   "________________________________________"
   Resposta: "Returns the user with ID 1."

3. POST /api/users
   "________________________________________"
   Resposta: "Creates a new user."

4. PUT /api/users/1
   "________________________________________"
   Resposta: "Updates the user with ID 1."

5. DELETE /api/users/1
   "________________________________________"
   Resposta: "Deletes the user with ID 1."

------------------------------------------------------------
PARTE 3 — LEITURA DE RESPONSE
------------------------------------------------------------

Leia esta resposta JSON:

```json
{
  "status": 200,
  "data": {
    "id": 1,
    "name": "John Doe",
    "email": "john@example.com"
  },
  "message": "User found successfully"
}
```

1. "What is the status code?"
   Resposta: 200

2. "What data is returned?"
   Resposta: User data with id, name, and email

3. "What does the message say?"
   Resposta: "User found successfully"

4. "Is this a success or error response?"
   Resposta: Success (status 200)

------------------------------------------------------------
PARTE 4 — DESCREVA O ERRO
------------------------------------------------------------

```json
{
  "status": 404,
  "error": "Not Found",
  "message": "User with ID 999 does not exist"
}
```

1. "What went wrong?"
   Resposta: The user with ID 999 was not found.

2. "What does 404 mean?"
   Resposta: Not Found (recurso não encontrado).

3. "How would you describe this to a colleague?"
   Resposta: "The API returned a 404 because the user with ID 999 doesn't exist in the database."
