# Módulo 03 — Vocabulário Web

## O Que Você Vai Aprender

Domine os termos essenciais de web development que aparecem em toda documentação, tutoriais e conversas técnicas.

### Objetivos

- Aprender vocabulário de redes e web
- Entender termos de APIs e requisições HTTP
- Diferenciar conceitos como client/server, frontend/backend
- Usar termos corretamente em frases

---

## Vocabulário do Módulo

### Navegadores e Internet

| Inglês | Português | Exemplo |
|--------|-----------|---------|
| Browser | Navegador | "Open the browser." |
| Website | Site | "The website is live." |
| Web page | Página web | "Load the web page." |
| URL | URL | "Copy the URL." |
| Link | Link | "Click the link." |
| Search engine | Mecanismo de busca | "Use a search engine." |
| Download | Download | "Download the file." |
| Upload | Upload | "Upload the image." |
| Refresh | Atualizar | "Refresh the page." |

### Client e Server

| Inglês | Português | Exemplo |
|--------|-----------|---------|
| Client | Cliente | "The client sends a request." |
| Server | Servidor | "The server processes the request." |

| Response | Resposta | "The response was 200 OK." |
| Endpoint | Endpoint | "Call the API endpoint." |
| API | API | "Use the API to get data." |
| HTTP | HTTP | "HTTP is the protocol." |
| HTTPS | HTTPS | "Use HTTPS for security." |
