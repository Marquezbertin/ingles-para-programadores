PARTE 1 — VERSÃO vs REVISÃO DE UMA FUNÇÃO
------------------------------------------------------------

Leia a função e documente:

```javascript
// Calculates the shipping cost based on weight and destination
// @param {number} weight - The weight of the package in kg
// @param {string} country - The destination country code
// @returns {number} The shipping cost in USD
function calculateShipping(weight, country) {
  const baseRate = 5;
  const ratePerKg = 2;
  const internationalFee = 10;

  let cost = baseRate + (weight * ratePerKg);

  if (country !== 'US') {
    cost += internationalFee;
  }

  return cost;
}
```

1. O que a função faz?
   Resposta: Calcula o custo de envio baseado em peso e país

2. Quais parâmetros recebe?
   Resposta: weight (número em kg) e country (código do país)

3. O que retorna?
   Resposta: O custo do envio em dólares

4. Como é calculado?
   Resposta: Taxa base 5 + (peso * 2) + taxa internacional (10 para países fora dos EUA)

    "id": 1,
    "name": "John"
  }
}

### Error Responses
- 400: Missing email or password
- 401: Invalid credentials
- 500: Server error
