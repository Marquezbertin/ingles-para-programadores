# Módulo 11 — Escrita Técnica

## O Que Você Vai Aprender

Aprenda a escrever README, documentação técnica e commits de qualidade em inglês.

### Objetivos

- Escrever READMEs profissionais em inglês
- Criar documentação técnica clara e organizada
- Escrever mensagens de commit consistentes
- Aplicar boas práticas de escrita técnica

---

## Princípios de Escrita Técnica

| Princípio | Explicação |
|-----------|------------|
| Clareza | Ser claro, sem ambiguidade |
| Concisão | Ser direto, sem enrolação |
| Precisão | Usar termos exatos |
| Escaneabilidade | Facilitar leitura rápida |
| Consistência | Usar mesmo termos/estilo sempre |

### Regras Práticas

1. Use voz ativa: "The function returns..." (não "is returned by")
2. Use verbo no presente: "The app starts..." (não "will start")
3. Use frases curtas: uma ideia por frase
4. Use termos técnicos corretamente
5. Evite jargões desnecessários

---

## Estrutura de um README

```
# Project Name (Título)

[Badge de status] [Badge de versão] [Licença]

## Description
[O que o projeto faz?]

## Installation
[Como instalar?]

## Usage
[Como usar? Com exemplos]

## API / Documentation
[Referência se aplicável]

## Contributing
[Como contribuir?]

## License
[Licença]
```
