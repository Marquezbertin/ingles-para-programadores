EXERCÍCIO 02 — Escrever um README Completo
Dificuldade: Difícil
============================================================

OBJETIVO: Escrever um README profissional em inglês.

------------------------------------------------------------
PARTE 1 — VOCABULÁRIO PARA README
------------------------------------------------------------

| Em Inglês | Em Português |
|-----------|--------------|
| "A library for..." | "Uma biblioteca para..." |
| "A tool to help you..." | "Uma ferramenta para te ajudar a..." |
| "Get started" | "Comece aqui" |
| "Clone the repository" | "Clone o repositório" |
| "Install dependencies" | "Instale as dependências" |
| "Run the app" | "Rode a aplicação" |
| "For example" | "Por exemplo" |
| "This will..." | "Isso vai..." |
| "If you encounter..." | "Se você encontrar..." |
| "Feel free to..." | "Sinta-se a vontade para..." |

------------------------------------------------------------
PARTE 2 — ESCREVA O README
------------------------------------------------------------

Complete o README de uma CLI chamada "json-tools":

```
# json-tools

A __________________ for working with JSON files
in the command line. It can validate, format, and
merge JSON data.

## Description
json-tools is a lightweight CLI that helps developers
__________ JSON files without opening an editor.

## Prerequisites
- Node.js v16 or __________
- npm or __________

## Installation
npm install -g json-tools

## Usage

Validate a file:
json-tools validate data.json
This will __________ if the JSON is valid.

Format a file:
json-tools format data.json
This will __________ the JSON with proper indentation.

## Contributing
__________ to submit a pull request or open an issue.

## License
MIT
```

Respostas: library, validate/manipulate, higher, yarn,
check/output/print, format/prettify, Feel free

------------------------------------------------------------
PARTE 3 — ESCREVA DO ZERO
------------------------------------------------------------

Escreva um README para uma biblioteca de validação de CPF
chamada "cpf-validator":

Descrição (concentre-se no que faz e por quê):

1. Título: _______________________
2. Descrição: "_______________________"
3. Instalação: "npm install cpf-validator"
4. Uso (com exemplo): "_______________________"
5. Contribuição: "_______________________"
6. Licença: "MIT"

Resposta (exemplo):
"# cpf-validator
A JavaScript library to validate Brazilian CPF numbers.
## Usage:
import { isValid } from 'cpf-validator';
const result = isValid('123.456.789-09'); // true/false
## Contributing:
Feel free to open an issue or submit a PR.
## License: MIT"

PARTE 4 — DICAS DE ESCRITA
------------------------------------------------------------

Verdadeiro ou falso:

1. ( ) O README deve ser curto, mesmo que incompleto.
2. ( ) Exemplos de código tornam o README melhor.
3. ( ) O README deve ser em português se o projeto é brasileiro.
4. ( ) Um bom README descreve o problema que resolve.
5. ( ) Screenshots ajudam em projetos de UI.

Respostas: 1-F, 2-V, 3-F (inglês é padrão internacional),
4-V, 5-V
