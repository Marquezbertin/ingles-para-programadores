============================================================
EXERCÍCIO 01 — Estrutura de um README
Dificuldade: Médio
============================================================

OBJETIVO: Entender a estrutura padrão de um README.

------------------------------------------------------------
PARTE 1 — SEÇÕES DE UM README
------------------------------------------------------------

Complete a estrutura:

1. __________ — Nome do projeto
2. __________ — O que o projeto faz (1-2 frases)
3. __________ — Requisitos e dependências
4. __________ — Como instalar
5. __________ — Como usar (com exemplos)
6. __________ — Como contribuir
7. __________ — Licença

Respostas: Título/Title, Descrição/Description, Pré-requisitos/
Prerequisites, Instalação/Installation, Uso/Usage,
Contribuição/Contributing, Licença/License

------------------------------------------------------------
PARTE 2 — BONS E MAUS READMEs
------------------------------------------------------------

Compare os dois READMEs:

README A:
"# Minha lib

é uma lib massa para fazer coisas, me ajuda se tiver
problemas, é só chamar. tem muitas funções e tal.
instala com npm se quiser, não precisa muito.
sem docs direito."

README B:
"# DataValidator

A JavaScript library for validating and sanitizing user
input in web applications.

## Installation

npm install data-validator

## Usage

```javascript
import { validateEmail } from 'data-validator';

const isValid = validateEmail('user@example.com');
// true
```

## API

### validateEmail(email)

Returns true if the email is a valid format.

## Contributing

Please read CONTRIBUTING.md before submitting a
pull request.

## License

MIT"

Perguntas:
1. Qual README é profissional? → B
2. Quais elementos tornam o B melhor?
   Resposta: Estrutura clara, em inglês, com exemplos de uso,
   API documentada, seções de contribuição e licença

3. O que o README A não tem?
   Resposta: Estrutura, exemplos, documentação de API, inglês

------------------------------------------------------------
PARTE 3 — COLOCAR EM ORDEM
------------------------------------------------------------

Ordene as seções de um README:

( ) Usage
( ) License
( ) Description
( ) Installation
( ) Contributing
( ) Title
( ) Prerequisites

Ordem correta: 5, 6, 2, 4, 7, 1, 3

------------------------------------------------------------
PARTE 4 — CHECKLIST DO README
------------------------------------------------------------

Marque o que um bom README deve ter:

[ ] Título claro
[ ] Descrição concisa (o que/por quê)
[ ] Pré-requisitos listados
[ ] Instruções de instalação step-by-step
[ ] Exemplo de uso
[ ] Documentação da API (se aplicável)
[ ] Como contribuir
[ ] Licença
[ ] Badges de status
[ ] Screenshots (se aplicável)
