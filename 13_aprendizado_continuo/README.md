# Módulo 13 — Aprendizado Contínuo

## O Que Você Vai Aprender

Aprenda a manter seu inglês técnico em evolução constante e aproveitar os melhores recursos e comunidades.

### Objetivos

- Criar um plano de aprendizado contínuo
- Encontrar os melhores recursos em inglês
- Participar de comunidades internacionais
- Manter a consistência no estudo

## Estratégias de Aprendizado Contínuo

### 1. Rotina Diária

| Atividade | Tempo |
|-----------|-------|
| Reading (docs, blogs) | 15 min |
| Listening (podcast, video) | 15 min |
| Writing (commits, PRs) | 10 min |
| Speaking (shadowing, calls) | 10 min |

### 2. Recursos Recomendados

**Documentação:**
- MDN Web Docs

- Python Official Docs
