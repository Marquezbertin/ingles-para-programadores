# Módulo 02 — Vocabulário de Computação

## O Que Você Vai Aprender

Aprofunde-se nos termos técnicos essenciais de computação que todo programador precisa dominar.

### Objetivos

- Dominar vocabulário técnico de computação
- Usar termos corretamente em frases
- Entender a diferença entre termos similares
- Aplicar vocabulário em contextos reais de programação

---

## Teoria

### Por Que Vocabulário Técnico Importa?

Não basta saber "computador" em inglês. Você precisa saber os termos específicos que aparecem em:
- Mensagens de erro
- Documentação técnica
- Reuniões de time
- Comentários de código
- Issues e pull requests

---
