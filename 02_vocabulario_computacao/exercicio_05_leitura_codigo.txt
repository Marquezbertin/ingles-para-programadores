Leia o código abaixo e os comentários em inglês.
Responda as perguntas.

```javascript
// This function calculates the total price
// It takes an array of items and returns the sum
function calculateTotal(items) {
  // Initialize the total variable
  let total = 0;

  // Loop through each item in the array
  for (let i = 0; i < items.length; i++) {
    // Add the item price to the total
    total += items[i].price;
  }

  // Return the final total
  return total;
}
```

1. O que esta função faz?
   Resposta: Calcula o preço total de uma lista de itens

2. Qual é o parâmetro da função?
   Resposta: items (um array de itens)

3. O que "initialize" significa aqui?
   Resposta: Inicializar (criar com valor inicial)

4. O que o loop "for" faz?
   Resposta: Percorre cada item do array

5. O que a função retorna?
   Resposta: O valor total (total)

6. Traduza o comentário final para português:
   "Return the final total"
   Resposta: Retorne o total final

PARTE 3 — CÓDIGO COM DEPENDÊNCIAS
------------------------------------------------------------

Leia e responda:

```python
# Import the required libraries
import json
import requests

# This module handles API calls
# It sends a GET request to the specified URL
# and returns the parsed JSON response

def fetch_data(url):
    # Make the API request
    response = requests.get(url)

    # Check if the request was successful
    if response.status_code == 200:
        # Parse the JSON data
        data = json.loads(response.text)
        return data
    else:
        # Handle the error
        return None
```

1. O que "import" faz?
   Resposta: Importa bibliotecas/módulos necessários

2. O que esta função "fetch_data" faz?
   Resposta: Faz uma requisição GET à URL e retorna dados JSON

3. O que verifica "if response.status_code == 200"?
   Resposta: Verifica se a requisição foi bem-sucedida

4. O que acontece se não for 200?
   Resposta: Retorna None (tratamento de erro)

5. O que "parse" significa neste contexto?
   Resposta: Analisar/converter (transformar texto em objeto)
