PARTE 3 — CENÁRIO: CODE REVIEW
------------------------------------------------------------

Leia este código e responda:

```javascript
function getUserById(users, id) {
  for (let i = 0; i < users.length; i++) {
    if (users[i].id === id) {
      return users[i];
    }
  }
  return null;
}
```

1. "What does this function do?"
   Resposta: Encontra e retorna um usuário pelo ID

2. "What are the parameters?"
   Resposta: users (array de usuários) e id (identificador)

3. "What does it return if no user is found?"
   Resposta: null

4. "How could you improve this function?"
   Resposta: Usar .find() em vez de loop, ou adicionar validação
