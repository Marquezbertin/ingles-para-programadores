------------------------------------------------------------
PARTE 3 — LEITURA DE CÓDIGO
------------------------------------------------------------

Leia este código e responda em inglês:

```javascript
const user = {
  name: "John",
  age: 30,
  isActive: true
};

const numbers = [1, 2, 3, 4, 5];
const firstName = user.name;
const lastNumber = numbers[numbers.length - 1];
```

1. "user" é um(a) __________ (object/variable/array)
   Resposta: object

2. "name" é uma __________ do objeto
   Resposta: key

3. "John" é o __________ da key "name"
   Resposta: value

4. "numbers" é um(a) __________
   Resposta: array

5. "isActive" é do tipo __________
   Resposta: boolean

6. "30" é um(a) __________
   Resposta: number

7. O que é "firstName"?
   Resposta: É uma variável com o valor da key "name" do objeto user

8. Qual é o valor de "lastNumber"?
   Resposta: 5
