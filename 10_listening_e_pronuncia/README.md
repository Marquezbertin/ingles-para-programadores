# Módulo 10 — Listening e Pronúncia

## O Que Você Vai Aprender

Desenvolva sua compreensão auditiva e melhore a pronúncia de termos técnicos em inglês.

### Objetivos

- Melhorar a compreensão auditiva de conteúdo técnico
- Pronunciar termos técnicos corretamente
- Entender vídeos, podcasts e talks técnicas
- Desenvolver confiança para falar em inglês

---

## Estratégias de Listening

### 1. Escuta Ativa

| Estratégia | Como |
|-----------|------|
| Shadowing | Repetir em voz alta após o falante |
| Chunking | Dividir frases em blocos |
| Note-taking | Anotar palavras novas |
| Full immersion | Assistir conteúdo sem legendas |

### 2. Recursos de Listening

| Recurso | Exemplo |
|---------|---------|
| YouTube | Traversy Media, The Net Ninja |
| Podcasts | Syntax, JS Party |
| TED Talks | GitHub Universe, JSConf |
| Documentação em áudio | MDN podcasts |
| Entrevistas | Coding with kevinPowell |

### 3. Técnica de "Chunking"

Em vez de tentar entender palavra por palavra:

- "The server is down because..." → "o servidor está fora porque..."
- "We can deploy this" → "podemos publicar isso"
- "Let's go over the code" → "vamos revisar o código"
