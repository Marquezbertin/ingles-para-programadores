# Módulo 06 — Leitura de Documentação

## O Que Você Vai Aprender

Aprenda a ler e entender documentação técnica em inglês, incluindo MDN, Stack Overflow, GitHub e documentação oficial de linguagens e frameworks.

### Objetivos

- Entender a estrutura da documentação técnica
- Navegar no MDN, Stack Overflow e GitHub
- Extrair informações relevantes de docs
- Usar documentação como ferramenta de aprendizado
