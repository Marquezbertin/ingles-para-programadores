# Módulo 14 — Projeto: Ler Docs

## O Que Você Vai Aprender

Projeto prático: ler documentação real de Python e JavaScript para consolidar todo o vocabulário aprendido.

### Objetivos

- Ler documentação real em inglês
- Extrair informações essenciais
- Aplicar o vocabulário de leitura de docs
- Criar resumos e anotações em inglês

---

## Sobre este Módulo

Este é um módulo de **projeto prático**. Em vez de apenas estudar vocabulário, você vai colocar tudo em prática lendo documentação real.

### Metodologia

Para cada trecho de documentação:

1. **Leia** o trecho completo uma vez
2. **Identifique** o conteúdo principal
3. **Extraia** os termos-chave
4. **Responda** as perguntas
5. **Resuma** em suas palavras (em inglês)

---

## O que é Documentação Real

### Documentação Python (docs.python.org)

- Tutorial
- Library Reference
- Language Reference
- How-To Guides

### Documentação JavaScript (MDN)

- Reference (métodos, objetos)
- Guides
- Tutorials

---

## Guia de Leitura

### Leitura Eficiente

| Etapa | Ação |
|-------|------|
| Scan | Leia títulos, headings, code |
| Skim | Leia primeiras frases de cada parágrafo |
| Read | Leia o trecho importante em detalhe |
| Note | Anote termos desconhecidos |
| Apply | Use em um exemplo |
