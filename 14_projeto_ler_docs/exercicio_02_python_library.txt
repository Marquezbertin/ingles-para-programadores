Leia o trecho sobre list.append() (adaptado):

"list.append(x)

Adds an item x to the end of the list.

Examples:
>>> fruits = ['apple', 'banana']
>>> fruits.append('cherry')
>>> fruits
['apple', 'banana', 'cherry']

list.extend(iterable)

Extends the list by appending all the items from
the iterable. Equivalent to a[len(a):] = iterable.

Examples:
>>> fruits = ['apple', 'banana']
>>> fruits.extend(['cherry', 'date'])
>>> fruits
['apple', 'banana', 'cherry', 'date']

list.insert(i, x)

Inserts an item at a given position. The first
argument i is the index of the element before which
to insert.

Examples:
>>> fruits = ['apple', 'banana']
>>> fruits.insert(1, 'cherry')
>>> fruits
['apple', 'cherry', 'banana']"

------------------------------------------------------------
PARTE 2 — COMPREENSÃO
------------------------------------------------------------

1. "What does append() do?"
   Resposta: Adds an item to the end of the list

2. "What is the difference between append and extend?"
   Resposta: append adds one item; extend adds multiple items from an iterable

3. "What does the first argument of insert() mean?"
   Resposta: The index before which the item will be inserted

4. "Where would you add an item at the beginning?"
   Resposta: list.insert(0, item)
