------------------------------------------------------------
PARTE 3 — LEITURA DE TESTE
------------------------------------------------------------

Leia este teste em JavaScript:

```javascript
describe('Login function', () => {
  test('should return true for valid credentials', () => {
    const result = login('admin', 'password123');
    expect(result).toBe(true);
  });

  test('should return false for invalid password', () => {
    const result = login('admin', 'wrong');
    expect(result).toBe(false);
  });

  test('should throw error for empty username', () => {
    expect(() => login('', 'password123')).toThrow('Username required');
  });
});
```

1. Quantos test cases há?
   Resposta: 3

2. O que o primeiro teste verifica?
   Resposta: Login com credenciais válidas retorna true

3. O que happen quando o username está vazio?
   Resposta: Lança erro "Username required"

4. O que significa "describe" neste contexto?
   Resposta: Descreve o grupo de testes (login function)

5. O que significa "expect...toBe"?
   Resposta: Espera que o resultado seja igual ao esperado
