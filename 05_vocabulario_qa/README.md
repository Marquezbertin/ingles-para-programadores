# Módulo 05 — Vocabulário QA

## O Que Você Vai Aprender

Domine o vocabulário de Quality Assurance e metodologias ágeis essencial para trabalhar em equipes de desenvolvimento.

### Objetivos

- Aprender termos de QA e testes
- Entender vocabulário de metodologias ágeis
- Descrever bugs e features em inglês
- Participar de sprints e retrospectivas

---

## Vocabulário do Módulo

### Testes

| Inglês | Português | Exemplo |
|--------|-----------|---------|
| Test | Teste | "Write a test." |
| Unit test | Teste unitário | "Add unit tests." |
| Integration test | Teste de integração | "Run integration tests." |
| End-to-end test | Teste ponta a ponta | "Create E2E tests." |
| Test case | Caso de teste | "Write test cases." |
| Test suite | Suíte de testes | "The test suite passes." |
| Coverage | Cobertura | "Improve test coverage." |
| Pass | Passar | "All tests pass." |
| Fail | Falhar | "The test failed." |
| Assertion | Asserção | "Add an assertion." |

### Bugs e Issues

| Inglês | Português | Exemplo |
|--------|-----------|---------|
| Bug | Bug | "I found a bug." |
| Issue | Issue | "Create an issue." |
| Defect | Defeito | "There's a defect in the UI." |
| Regression | Regressão | "This change caused a regression." |
| Severity | Severidade | "What's the severity?" |
| Priority | Prioridade | "High priority bug." |
| Reproduce | Reproduzir | "Can you reproduce the bug?" |
| Workaround | Solução alternativa | "There's a workaround." |
| Fix | Correção | "Apply the fix." |
| Patch | Patch | "Release a patch." |

| Inglês | Português | Exemplo |
