============================================================
EXERCÍCIO 04 — NPM e Node em Inglês
Dificuldade: Médio
============================================================

OBJETIVO: Entender comandos NPM e mensagens em inglês.

------------------------------------------------------------
PARTE 1 — COMANDOS NPM
------------------------------------------------------------

| Comando | Significado |
|---------|-------------|
| npm init | Inicializar projeto |
| npm install | Instalar dependências |
| npm install pkg | Instalar pacote |
| npm uninstall pkg | Desinstalar pacote |
| npm update | Atualizar pacotes |
| npm run script | Rodar script |
| npm start | Iniciar aplicação |
| npm test | Rodar testes |
| npm run build | Compilar projeto |

------------------------------------------------------------
PARTE 2 — LEITURA DE package.json
------------------------------------------------------------

```json
{
  "name": "my-app",
  "version": "1.0.0",
  "scripts": {
    "start": "node server.js",
    "dev": "nodemon server.js",
    "test": "jest",
    "build": "webpack --mode production"
  },
  "dependencies": {
    "express": "^4.18.2"
  },
  "devDependencies": {
    "jest": "^29.0.0"
  }
}
```

1. Qual é o nome do projeto?
   Resposta: my-app

2. Qual versão?
   Resposta: 1.0.0

3. Como rodar o servidor?
   Resposta: npm start (node server.js)

4. Como rodar testes?
   Resposta: npm test (jest)

5. Qual é a dependência principal?
   Resposta: express ^4.18.2

6. Qual é a dependência de desenvolvimento?
   Resposta: jest ^29.0.0

------------------------------------------------------------
PARTE 3 — ERROS COMUNS DO NPM
------------------------------------------------------------

1. "npm ERR! code ERESOLVE"
   → ________________________________________

2. "npm WARN deprecated"
   → ________________________________________

3. "npm ERR! ENOENT: no such file or directory"
   → ________________________________________

Respostas:
1. Conflito de versões de dependências
2. Pacote depreciado (não deve ser usado)
3. Arquivo ou diretório não encontrado (provavelmente não há package.json)
