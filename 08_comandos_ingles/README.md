# Módulo 08 — Comandos em Inglês

## O Que Você Vai Aprender

Entenda comandos de terminal, mensagens de erro e logs em inglês para trabalhar com eficiência.

### Objetivos

- Aprender comandos CLI comuns em inglês
- Interpretar mensagens de erro
- Ler e entender logs de aplicação
- Usar comandos com confiança

---

## Vocabulário do Módulo

### Comandos de Terminal

| Comando | Significado | Exemplo |
|---------|-------------|---------|
| ls / dir | Listar arquivos | `ls -la` |
| cd | Mudar diretório | `cd /path` |
| pwd | Diretório atual | `pwd` |
| mkdir | Criar pasta | `mkdir new-folder` |
| rm | Remover | `rm file.txt` |
| cp | Copiar | `cp file.txt backup/` |
| mv | Mover/renomear | `mv old.txt new.txt` |
| cat | Ler arquivo | `cat README.md` |
| echo | Imprimir texto | `echo "Hello"` |
| grep | Buscar em texto | `grep "error" log.txt` |
| find | Encontrar arquivos | `find . -name "*.js"` |
| chmod | Mudar permissões | `chmod +x script.sh` |
| git | Controle de versão | `git status` |
| npm | Gerenciador de pacotes | `npm install` |
| node | Rodar JavaScript | `node app.js` |

### Mensagens de Erro

| Em Inglês | Em Português |
|-----------|--------------|
| "Permission denied" | "Permissão negada" |
| "File not found" | "Arquivo não encontrado" |
| "Command not found" | "Comando não encontrado" |
| "Syntax error" | "Erro de sintaxe" |
| "Connection refused" | "Conexão recusada" |
| "Timeout" | "Tempo esgotado" |
| "Out of memory" | "Memória esgotada" |
| "Stack overflow" | "Estouro de pilha" |

### Logs

| Nível | Significado |
|-------|-------------|
| DEBUG | Informação de debug |
| INFO | Informação geral |
| WARN | Aviso |
| ERROR | Erro |
| FATAL | Erro fatal |
