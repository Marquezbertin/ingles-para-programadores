## Sobre o Projeto

Este repositório é um curso completo de inglês técnico voltado para programadores com 12+ anos de experiência em tecnologia. Faz parte do **Laboratório Tech Social**, um ecossistema de projetos educacionais para desenvolvedores.

Aqui você vai aprender:

- Vocabulário técnico essencial para o dia a dia de um dev
- Como ler documentação em inglês com fluência
- Como escrever commits, PRs e issues em inglês
- Como participar de reuniões e tech talks em inglês
- Como contribuir para projetos open source internacionais

---

## Como Usar

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/laboratorio-tech-social/ingles-para-programadores.git
   ```

2. **Siga a ordem dos módulos:** Cada módulo constrói sobre o anterior. Comece pelo `01_fundamentos` e avance até `15_projeto_contribuir`.

3. **Faça todos os exercícios:** Cada módulo contém 6 exercícios práticos em arquivos `.txt`. Resolva todos antes de avançar.

4. **Use no seu dia a dia:** Aplique o vocabulário aprendido em commits, PRs, issues e reuniões reais.

5. **Pratique todos os dias:** Mesmo que sejam apenas 15 minutos, a consistência é chave.
